    02 / approach

    Lessons from production.

    1. 01

      Let the model judge. Let code do the math.

      My negotiation agent once quoted the wrong prices. The fix was to keep the language model on tone and strategy and move every number into deterministic JavaScript. Now a pricing bug is a code bug, so it can be tested.

    2. 02

      Measure, then claim.

      Cost per lead, hit rates, API limits: I count them from execution logs before they go in a report. A guess about volume is a bug that just hasn't shown up yet.

    3. 03

      Chase the first error, not the loudest.

      A Telegram bot started throwing "query too old" errors. The real cause was a deleted Google Sheet one step upstream, which backed up the update queue for 55 minutes. Every fix since then starts from the first failure in the timeline.

    4. 04

      Fail loud. Never fail silent.

      Each system ships with its guards: a global error workflow, a balance guard for AI credits, login alerts and regression tests that replay live traffic with sending turned off.
